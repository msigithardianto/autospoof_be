# Koleksi PP (foto profil) untuk /pp

Taruh gambar di sub-folder per kategori. Nama folder = nama kategori di command.

```
assets/pp/
  cowok/    a.png  b.jpg ...
  cewek/    ...
  anime/    ...
  couple/   1_1.png 1_2.png   2_1.png 2_2.png   (pasangan: <id>_1 dan <id>_2, dikirim bersamaan)
```

- Format: png, jpg, jpeg, webp, gif. Disarankan persegi (1:1), maks ±8 MB per file.
- Setelah menambah folder baru, deploy ulang agar kategori muncul sebagai pilihan di `/pp`.
- Pakai gambar milikmu sendiri atau yang berlisensi/izin pemiliknya.
